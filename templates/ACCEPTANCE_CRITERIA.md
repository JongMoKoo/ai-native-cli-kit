# Acceptance criteria template
- [ ] Inputs and schemas listed; missing/duplicate/invalid policies defined
- [ ] Outputs, format, and destination listed
- [ ] Boundary values tested (inclusive vs exclusive)
- [ ] Data joins validated (no unexpected many-to-many)
- [ ] Security and data egress reviewed
- [ ] Actual tests run; command and summary recorded
- [ ] Limitations and unresolved assumptions stated
- [ ] No exam data committed or transmitted
